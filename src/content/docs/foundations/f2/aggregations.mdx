An **aggregation** boils many numbers down to one: a total, an average, a maximum. In F1 you wrote
these yourself with the accumulator pattern ([Loops](/foundations/f1/loops/)). NumPy has them built in,
and adds one powerful extra: you can aggregate along a chosen **axis**, so one line gives you, say,
the average of every column of a table.

## Whole-array summaries

```python
import numpy as np

x = np.array([4, 8, 15, 16, 23, 42])
print(x.sum(), x.mean(), x.min(), x.max())
print(x.std().round(3), np.median(x))
print(x.argmin(), x.argmax())
```

```text title="Output"
108 18.0 4 42
12.315 15.5
0 5
```

- `sum`, `mean`, `min` and `max` do what they say. Each is available as a method (`x.sum()`) and as a
  function (`np.sum(x)`).
- `np.median` is the middle value once sorted (here halfway between 15 and 16). It is a function only.
- `argmin` and `argmax` give the **position** of the smallest or largest value, not the value itself.
  `x.argmax()` is 5 because the maximum, 42, sits at index 5.

### Standard deviation

The **standard deviation** measures how spread out values are around their mean. For values
$x_1, \dots, x_n$ with mean $\bar{x}$ (read "x bar"):

$$\sigma = \sqrt{\frac{1}{n}\sum_{i=1}^{n} (x_i - \bar{x})^2}$$

In words: take each value's distance from the mean, square it, average those squares, and take the
square root. The average of the squares, before the square root, is the **variance**.

```python
x = np.array([2, 4, 4, 4, 5, 5, 7, 9])
print(x.mean(), x.std(), x.var())
print(x.std(ddof=1).round(4))
```

```text title="Output"
5.0 2.0 4.0
2.1381
```

:::note[Why ddof=1 gives a different answer]
NumPy divides by $n$ by default. Statistics books (and pandas) often divide by $n - 1$ instead, which
gives a slightly larger value that is a better estimate when your data is a sample from a bigger
population. `ddof=1` switches NumPy to $n - 1$. F5 explains why. For now, just know the two
conventions exist, so a small mismatch between NumPy and pandas does not puzzle you.
:::

## Choosing an axis

For a 2D array you usually want a summary **per column** or **per row**, not of everything at once.
That is what the `axis` argument does. Here are 3 shops (rows) and 4 days (columns) of sales:

```python
sales = np.array([[3, 5, 2, 4],
                  [6, 1, 7, 2],
                  [4, 4, 4, 4]])
print(sales.sum())
print(sales.sum(axis=0))
print(sales.sum(axis=1))
print(sales.mean(axis=1))
```

```text title="Output"
46
[13 10 13 10]
[14 16 16]
[3.5 4.  4. ]
```

The <Term id="axis" /> you name is the one that **disappears**:

- The shape is `(3, 4)`. `axis=0` is the first dimension, the rows. Summing over it leaves shape `(4,)`:
  one total per **day** (column).
- `axis=1` is the columns. Summing over it leaves shape `(3,)`: one total per **shop** (row).

If you mix them up, check the shape of the result: a `(3, 4)` array summed over `axis=0` must give 4
numbers. In ML data, rows are examples and columns are features, so `X.mean(axis=0)` is "the average of
each feature", exactly what you used for standardising in [the last lesson](/foundations/f2/broadcasting/).

`argmax` takes an axis too:

```python
print(sales.argmax(axis=1))
print(sales.max(axis=0))
```

```text title="Output"
[1 2 0]
[6 5 7 4]
```

`sales.argmax(axis=1)` gives the best day for each shop. Shop 0's best day is day 1 (sales 5). Shop 2 sold
4 every day; with a tie, `argmax` returns the **first** position, 0.

## Worked example: accuracy from model scores

A classifier usually outputs one score per class for each example. The predicted class is the one with the
highest score, which is `argmax` along the class axis:

```python
logits = np.array([[2.0, 1.0, 0.1],
                   [0.5, 2.5, 0.3]])
pred = logits.argmax(axis=1)
labels = np.array([0, 2])
print(pred)
print((pred == labels).mean())
```

```text title="Output"
[0 1]
0.5
```

Two examples (rows), three classes (columns). The model predicts class 0 for the first example and
class 1 for the second. The true labels are 0 and 2, so it got one of two right: accuracy 0.5. This
exact line, `(pred == labels).mean()`, will appear in nearly every classifier you train.

## keepdims: keep the shape for broadcasting

Suppose you want each shop's sales as a **fraction** of that shop's total. You need to divide each row by
its own sum. But `sales.sum(axis=1)` has shape `(3,)`, which would line up with the 4 columns and fail.
`keepdims=True` keeps the collapsed axis with size 1, giving a column of shape `(3, 1)` that broadcasts
across each row:

```python
print(sales.sum(axis=1, keepdims=True))
share = sales / sales.sum(axis=1, keepdims=True)
print(share.round(2))
print(share.sum(axis=1))
```

```text title="Output"
[[14]
 [16]
 [16]]
[[0.21 0.36 0.14 0.29]
 [0.38 0.06 0.44 0.12]
 [0.25 0.25 0.25 0.25]]
[1. 1. 1.]
```

Every row now sums to 1. Turning scores into proportions this way is a step of the *softmax* function,
which you will build in F9.

## Aggregating a mask

Combine masks from [lesson 2](/foundations/f2/indexing-and-masks/) with an axis to count per row or column:

```python
scores = np.array([[70, 80], [90, 60], [50, 100]])
print((scores > 75).sum(axis=0))
print((scores > 75).any(axis=1))
print((scores > 75).all(axis=1))
```

```text title="Output"
[1 2]
[ True  True  True]
[False False False]
```

Here 3 students (rows) took 2 tests (columns). One student scored above 75 on test 0 and two on test 1.
`any` asks "is at least one True?" and `all` asks "are all True?". Each student beat 75 on at least one
test, but nobody beat it on both.

## A few more useful ones

```python
x = np.array([3, 1, 4, 1, 5])
print(np.cumsum(x))
print(np.sort(x), np.argsort(x))
vals, counts = np.unique(x, return_counts=True)
print(vals, counts)
```

```text title="Output"
[ 3  4  8  9 14]
[1 1 3 4 5] [1 3 0 2 4]
[1 3 4 5] [2 1 1 1]
```

- `np.cumsum` gives running totals.
- `np.sort` returns a sorted copy; `np.argsort` gives the positions that would sort the array.
- `np.unique` lists the distinct values, and with `return_counts=True` how often each appears,
  like `Counter` from F1.

### Missing values poison aggregations

If an array contains `nan`, most aggregations return `nan`. The `nan`-prefixed versions skip them:

```python
x = np.array([1.0, np.nan, 3.0])
print(x.mean(), np.nanmean(x))
print(np.isnan(x))
```

```text title="Output"
nan 2.0
[False  True False]
```

pandas, in lesson 7, handles missing values more conveniently, and skips them by default.

## Summary

- `sum`, `mean`, `std`, `var`, `min`, `max` summarise; `argmin`/`argmax` give positions (the first one on ties).
- The `axis` you name disappears: on shape `(rows, cols)`, `axis=0` gives one value per column, `axis=1` one per row.
- `keepdims=True` keeps a size-1 axis so the result broadcasts back, for example to divide rows by their totals.
- Accuracy: `(scores.argmax(axis=1) == labels).mean()`.
- `nan` makes aggregations return `nan`; use `np.nanmean` and friends, or clean the data first.
