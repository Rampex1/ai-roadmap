When a matrix acts on the plane, most vectors get knocked off their line: they come out pointing
somewhere new. But a few special directions survive: vectors along them are only stretched,
shrunk or flipped. These directions are a matrix's <Term id="eigenvector" text="eigenvectors" />
("eigen" is German for "own"), and they reveal what the matrix really does. They are behind PCA,
Google's original PageRank, the stability of training, and much more.

## The idea

Take

$$
A = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}
$$

and try a few vectors:

```python
import numpy as np

A = np.array([[2.0, 1.0],
              [1.0, 2.0]])
for v in ([1.0, 0.0], [1.0, 1.0], [1.0, -1.0]):
    print(v, "->", A @ np.array(v))
```

```text title="Output"
[1.0, 0.0] -> [2. 1.]
[1.0, 1.0] -> [3. 3.]
[1.0, -1.0] -> [ 1. -1.]
```

$(1, 0)$ is turned to $(2, 1)$, a new direction. But $(1, 1)$ goes to $(3, 3) = 3\,(1, 1)$: same line,
stretched by 3. And $(1, -1)$ comes out unchanged, which is "stretched by 1". These are the
eigenvectors of $A$, and the stretch factors 3 and 1 are the **eigenvalues**.

**Definition.** A nonzero vector $\mathbf{v}$ is an eigenvector of a square matrix $A$, with
eigenvalue $\lambda$ (the Greek letter lambda, a number), if

$$
A\mathbf{v} = \lambda\mathbf{v}
$$

- $\lambda > 1$: stretched. $0 < \lambda < 1$: shrunk. $\lambda < 0$: flipped to point the other way. $\lambda = 0$: squashed to zero, so $A$ is singular.
- Any multiple of an eigenvector is also an eigenvector with the same $\lambda$. What matters is the **direction**, so software returns them scaled to length 1.

Geometrically, $A$ stretches the plane by 3 along the diagonal line $y = x$ and leaves the line
$y = -x$ alone. In the basis of its eigenvectors, $A$ is just a diagonal scaling. That is the
whole point: **eigenvectors are the axes in which a matrix is simple.**

## Computing them with NumPy

```python
import numpy as np

A = np.array([[2.0, 1.0],
              [1.0, 2.0]])
vals, vecs = np.linalg.eig(A)
print(vals)
print(np.round(vecs, 4))
v = vecs[:, 0]                 # eigenvectors are the COLUMNS
print(np.allclose(A @ v, vals[0] * v))
```

```text title="Output"
[3. 1.]
[[ 0.7071 -0.7071]
 [ 0.7071  0.7071]]
True
```

Three things to watch:

1. The eigenvectors are the **columns** of `vecs`, not the rows. `vecs[:, i]` goes with `vals[i]`.
2. They have length 1, and the sign is arbitrary: $(-0.7071, -0.7071)$ would be just as correct.
3. `eig` does not promise any particular order.

For **symmetric** matrices ($A = A^\top$) use `np.linalg.eigh` instead. It is faster, always returns
real numbers, and sorts the eigenvalues in **ascending** order, so the largest is last:

```python
import numpy as np

A = np.array([[2.0, 1.0],
              [1.0, 2.0]])
vals, vecs = np.linalg.eigh(A)
print(vals)
print(np.round(vecs[:, -1], 4))    # eigenvector of the largest eigenvalue
```

```text title="Output"
[1. 3.]
[0.7071 0.7071]
```

## By hand, for 2 × 2 (optional)

$A\mathbf{v} = \lambda\mathbf{v}$ means $(A - \lambda I)\mathbf{v} = \mathbf{0}$ for a nonzero
$\mathbf{v}$. So $A - \lambda I$ squashes some direction to zero, which means it is singular:

$$
\det(A - \lambda I) = 0
$$

For our $A$: $(2 - \lambda)^2 - 1 = 0$, so $2 - \lambda = \pm 1$, giving $\lambda = 3$ or $\lambda = 1$.
Then solve $(A - \lambda I)\mathbf{v} = \mathbf{0}$ for each $\lambda$ to get the directions. You will
rarely do this by hand beyond $2 \times 2$; NumPy uses far better algorithms.

## Not every matrix has real eigenvectors

A rotation by 90° turns **every** direction, so no real vector stays on its line. Its eigenvalues
come out as complex numbers:

```python
import numpy as np

R = np.array([[0.0, -1.0],
              [1.0,  0.0]])
print(np.linalg.eigvals(R))
```

```text title="Output"
[0.+1.j 0.-1.j]
```

(`j` is Python's imaginary unit.) You will not need complex eigenvalues in this course; just know
that they signal rotation.

## Repeated multiplication

Eigenvectors tell you what happens when you apply the same matrix again and again. If
$A\mathbf{v} = \lambda\mathbf{v}$, then

$$
A^k\mathbf{v} = \lambda^k\mathbf{v}
$$

Write any starting vector as a combination of eigenvectors, $\mathbf{x} = c_1\mathbf{v}_1 + c_2\mathbf{v}_2$.
Then $A^k\mathbf{x} = c_1\lambda_1^k\mathbf{v}_1 + c_2\lambda_2^k\mathbf{v}_2$. The term with the
largest $|\lambda|$ grows fastest and soon dominates, so $A^k\mathbf{x}$ swings round to point along
the top eigenvector. This gives a simple algorithm, **power iteration**: keep multiplying by $A$ and
rescaling to length 1.

```python
import numpy as np

A = np.array([[2.0, 1.0],
              [1.0, 2.0]])
x = np.array([1.0, 0.0])
for step in range(6):
    x = A @ x
    x = x / np.linalg.norm(x)
    print(step, np.round(x, 4))
print("eigenvalue estimate:", round(x @ A @ x, 4))
```

```text title="Output"
0 [0.8944 0.4472]
1 [0.7809 0.6247]
2 [0.7328 0.6805]
3 [0.7158 0.6983]
4 [0.71   0.7042]
5 [0.7081 0.7061]
eigenvalue estimate: 3.0
```

The last line uses the fact that for a unit eigenvector, $\mathbf{v}^\top A\mathbf{v} = \lambda\,\mathbf{v}\cdot\mathbf{v} = \lambda$.
Google's original PageRank was essentially power iteration on the web's link matrix: the top
eigenvector scores every page.

The same maths explains a classic training problem. A recurrent neural network multiplies its
hidden state by the same weight matrix at every time step. If the largest $|\lambda|$ is above 1,
signals (and gradients) **explode** over long sequences; if all are below 1, they **vanish**.
Researchers care about weight matrices' eigenvalues for exactly this reason.

## Symmetric matrices: the best case

Symmetric matrices appear constantly in ML: $X^\top X$, covariance matrices, and the matrix of second
derivatives (the Hessian) used in optimisation. For a real symmetric matrix two very nice things hold (this is the
**spectral theorem**):

1. All eigenvalues are real.
2. Eigenvectors for different eigenvalues are perpendicular, and you can always pick $n$ of them that are mutually perpendicular unit vectors: an **orthonormal basis**.

Putting those eigenvectors as the columns of $Q$ and the eigenvalues on the diagonal of $\Lambda$
(capital lambda) gives

$$
A = Q\Lambda Q^\top
$$

Read right to left: rotate into the eigenvector basis ($Q^\top$), scale each axis ($\Lambda$), rotate
back ($Q$). Every symmetric matrix is "a stretch along perpendicular axes".

**Preview of PCA.** The covariance matrix of a dataset is symmetric. Its top eigenvector is the
direction in which the data spreads out most, and its eigenvalue is the variance along that
direction. Here is a cloud of correlated 2-D points:

```python
import numpy as np

rng = np.random.default_rng(0)
x = rng.normal(size=500)
X = np.column_stack([x, 0.5 * x + 0.2 * rng.normal(size=500)])
C = np.cov(X, rowvar=False)          # 2 x 2 covariance matrix
vals, vecs = np.linalg.eigh(C)
print(np.round(vals, 3))
print(np.round(vecs[:, -1], 3))
```

```text title="Output"
[0.028 1.295]
[-0.889 -0.458]
```

(Your sign may differ.)

Almost all the variance (1.295 out of about 1.323) lies along one direction, roughly
$(-0.89, -0.46)$. Flip the arbitrary sign and that is $(0.89, 0.46)$, which points along the line
$y \approx 0.5x$ the data was built from. That is PCA in
a nutshell, and the [final lesson](/foundations/f3/svd-and-pca/) does it properly.

## Summary

- $A\mathbf{v} = \lambda\mathbf{v}$: an eigenvector keeps its direction and is scaled by its eigenvalue $\lambda$.
- `np.linalg.eig` returns eigenvalues and unit eigenvectors as **columns**; for symmetric matrices use `eigh`, which sorts ascending.
- Eigenvalues solve $\det(A - \lambda I) = 0$. Rotations have complex eigenvalues.
- $A^k\mathbf{v} = \lambda^k\mathbf{v}$: repeated multiplication is dominated by the largest $|\lambda|$ (power iteration; exploding and vanishing signals).
- Symmetric matrices have real eigenvalues and orthonormal eigenvectors: $A = Q\Lambda Q^\top$. A covariance matrix's top eigenvector is the direction of greatest spread.
