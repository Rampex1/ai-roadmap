A <Term id="string" /> is a sequence of characters: letters, digits, spaces, punctuation, even
emoji. Text is everywhere in AI. Language models read and write it, and nearly every dataset has
some text in it, if only file names and column labels. Strings also introduce ideas,
**indexing** and **slicing**, that you will reuse for lists in lesson 6 and for NumPy arrays in F2.

## Making strings

Strings go in single or double quotes. Use one kind when the text contains the other:

```python
print("It's raining")
print('She said "hi"')
```

```text title="Output"
It's raining
She said "hi"
```

A backslash starts an *escape sequence* for characters you cannot type directly. The most
useful is `\n`, a new line:

```python
print("line one\nline two")
```

```text title="Output"
line one
line two
```

`len()` gives the number of characters. Spaces count:

```python
print(len("hello world"))
print(len(""))
```

```text title="Output"
11
0
```

`""` is the *empty string*: a string with no characters in it.

## Indexing: one character at a time

Each character has a position number called its **index**. Python counts from **0**, not 1,
which is called <Term id="zero-based-indexing" />. Negative indices count from the end, with
`-1` being the last character.

<Figure
  src={stringIndex}
  alt="The string PYTHON in six boxes. Above, indices 0 to 5. Below, negative indices -6 to -1. A bracket under Y, T and H shows that word[1:4] is YTH."
  caption="Positive indices count from 0 on the left; negative indices count from -1 on the right."
/>

```python
word = "PYTHON"
print(word[0])
print(word[2])
print(word[-1])
print(word[len(word) - 1])
```

```text title="Output"
P
T
N
N
```

The last valid index is `len(word) - 1`, here 5. Asking for `word[6]` is an `IndexError`:
there is no seventh character.

Why start at 0? Think of the index as "how many steps from the start". The first character is
zero steps in. Almost every programming language and every library you will use (NumPy,
pandas, PyTorch) counts this way, so it is worth getting comfortable now.

## Slicing: a piece of a string

A **slice** `s[start:stop]` gives the characters from index `start` up to, **but not
including**, index `stop`:

```python
word = "PYTHON"
print(word[1:4])
print(word[:2])
print(word[2:])
print(word[-3:])
```

```text title="Output"
YTH
PY
THON
HON
```

- Leave out `start` to begin at the start; leave out `stop` to go to the end.
- `stop` is excluded, so `word[1:4]` has `4 - 1 = 3` characters. A neat consequence:
  `word[:2] + word[2:]` is always the whole word.
- Slices never raise an `IndexError`; asking for too much just gives what exists. `word[4:100]` is `"ON"`.

An optional third number is the *step*. `s[::2]` takes every second character, and
`s[::-1]` walks backwards, reversing the string:

```python
print("abcdefgh"[::2])
print("stressed"[::-1])
```

```text title="Output"
aceg
desserts
```

## Strings cannot be changed

Strings are **immutable**: once made, a string never changes. You cannot do `word[0] = "J"`;
that raises a `TypeError`. Instead you build a *new* string and, if you like, attach the old
name to it:

```python
word = "PYTHON"
word = "J" + word[1:]
print(word)
```

```text title="Output"
JYTHON
```

This is why string methods, below, always *return* a new string and leave the original alone.

## String methods

A **method** is a function that belongs to a value. You call it with a dot:
`value.method(...)`. Strings come with dozens; these are the ones you will use most.

```python
raw = "  Hello, World!  "
print(raw.strip())
print(raw.lower())
print(raw.strip().upper())
print(raw.replace("World", "Python"))
print(raw)
```

```text title="Output"
Hello, World!
  hello, world!  
HELLO, WORLD!
  Hello, Python!  
  Hello, World!  
```

- `strip()` removes spaces (and newlines) from both ends.
- `lower()` and `upper()` change the case.
- `replace(old, new)` swaps every occurrence of `old`.
- Calls can be **chained**: `raw.strip().upper()` strips first, then upper-cases the result.
- The last line shows that `raw` itself never changed.

Splitting and joining are the bridge between text and lists:

```python
sentence = "the cat sat on the mat"
words = sentence.split()
print(words)
print(len(words))
print("-".join(words))
print("a,b,,c".split(","))
```

```text title="Output"
['the', 'cat', 'sat', 'on', 'the', 'mat']
6
the-cat-sat-on-the-mat
['a', 'b', '', 'c']
```

`split()` with no argument splits on any run of spaces and gives a **list** of words (lists are
lesson 6). `split(",")` splits on each comma exactly, which is how simple CSV files are read.
`"-".join(words)` goes the other way: it glues a list of strings together with `"-"` between them.
Splitting text into pieces is the very first step of how language models read text, a process
called *tokenisation* that you will meet in F10.

To search, use `in`, `count` and `find`:

```python
text = "banana"
print("nan" in text)
print(text.count("a"))
print(text.find("n"))
print(text.startswith("ban"))
```

```text title="Output"
True
3
2
True
```

`find` gives the index of the first match, or `-1` if there is none.

## Repetition

`*` with a string and an int repeats the string. It is handy for quick text layouts:

```python
print("ab" * 3)
print("-" * 20)
```

```text title="Output"
ababab
--------------------
```

## f-strings: putting values into text

In lesson 2 you built text with `+` and `str()`. An <Term id="f-string" /> is much
easier: put an `f` before the opening quote and write any expression inside curly braces.

```python
name = "Ada"
lessons_done = 3
print(f"{name} has finished {lessons_done} lessons.")
print(f"{name} needs {12 - lessons_done} more.")
```

```text title="Output"
Ada has finished 3 lessons.
Ada needs 9 more.
```

No `str()` needed: Python converts each value for you. After a colon inside the braces you can
add a *format spec* to control how numbers look. You will use these all the time to print
training progress:

```python
loss = 0.123456
accuracy = 0.9187
step = 42
print(f"step {step}: loss={loss:.3f}")
print(f"accuracy {accuracy:.1%}")
print(f"{step:5d}|")
```

```text title="Output"
step 42: loss=0.123
accuracy 91.9%
   42|
```

- `:.3f` shows a float with 3 decimal places.
- `:.1%` multiplies by 100 and adds a percent sign, with 1 decimal place.
- `:5d` pads a whole number to 5 characters wide, which lines up columns in a table.

## Summary

- Strings are sequences of characters. Index from 0; `-1` is the last character.
- `s[start:stop]` includes `start` and excludes `stop`; `s[::-1]` reverses.
- Strings are immutable. Methods like `strip`, `lower`, `replace`, `split` and `join` return new values.
- f-strings, `f"...{expr}..."`, put values into text; `:.2f` and `:.1%` control number formatting.
