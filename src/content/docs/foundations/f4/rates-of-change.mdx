Calculus is the mathematics of change. Machine learning needs it for one reason above all: training a
model means asking "if I nudge this parameter a little, how much does the error change?" That
question is about a **rate of change**, and this module teaches you to answer it.

We start where every calculus course starts: with a straight line.

## Functions as machines

A function takes an input and returns an output. You met them in Python in F1; maths uses the same
idea with shorter notation. $f(x) = 2x + 1$ means "the function $f$ takes a number $x$, doubles it and
adds 1". So $f(3) = 7$.

In ML, almost everything is a function: a model maps an input to a prediction, and a **loss**
function maps the model's parameters to a single number that says how wrong the model is. Training is
the search for parameters that make that number small.

## The slope of a line

For a straight line, the rate of change is the same everywhere. It is called the **slope**: how much
the output goes up for each one-unit step to the right.

$$
\text{slope} = \frac{\text{change in output}}{\text{change in input}} = \frac{f(b) - f(a)}{b - a}
$$

Here $a$ and $b$ are any two different inputs. People often write the changes as $\Delta y$ and
$\Delta x$ (the Greek letter delta, "change in"), so slope $= \Delta y / \Delta x$.

```python
def f(x):
    return 2 * x + 1

for a, b in [(0, 1), (1, 4), (-3, 5)]:
    slope = (f(b) - f(a)) / (b - a)
    print(a, b, slope)
```

```text title="Output"
0 1 2.0
1 4 2.0
-3 5 2.0
```

Whichever two points you pick, the slope of $2x + 1$ is 2. That is what "straight" means. The general
line $y = mx + c$ has slope $m$; $c$ is where it crosses the vertical axis.

- A positive slope means the output rises as the input rises.
- A negative slope means it falls.
- A slope of 0 means a flat line: changing the input does nothing to the output.

## Average rate of change

Most functions are not straight lines. You can still compute the same fraction between two points.
For a curve it is called the **average rate of change** over the interval from $a$ to $b$: it is the
slope of the straight line through the two points $(a, f(a))$ and $(b, f(b))$. That line is called a
**secant line**.

A road trip makes this concrete. Here is the distance driven after each hour:

```python
import numpy as np

t = np.array([0, 1, 2, 3, 4])             # hours
dist = np.array([0, 50, 130, 170, 260])   # km driven so far
rates = np.diff(dist) / np.diff(t)
print(rates)
print((dist[-1] - dist[0]) / (t[-1] - t[0]))
```

```text title="Output"
[50. 80. 40. 90.]
65.0
```

`np.diff` gives the change between neighbours, so `rates` is the average speed in each hour. Over the
whole trip the average is 65 km/h, but the car was never steady: it did 40 km/h in one hour and 90 in
another. And within any single hour the speed changed too. The speedometer shows something sharper:
the speed *right now*. That is the idea we are heading for.

## From a secant to a tangent

Take the curve $f(x) = x^2$ and stand at the point $a = 1$, where $f(1) = 1$. Pick a second point a
distance $h$ to the right and compute the secant slope:

$$
\frac{f(1 + h) - f(1)}{h}
$$

Now make $h$ smaller and smaller:

```python
def f(x):
    return x ** 2

a = 1.0
for h in [1.0, 0.1, 0.01, 0.001]:
    slope = (f(a + h) - f(a)) / h
    print(f"h = {h:<6} slope = {slope:.4f}")
```

```text title="Output"
h = 1.0    slope = 3.0000
h = 0.1    slope = 2.1000
h = 0.01   slope = 2.0100
h = 0.001  slope = 2.0010
```

The slopes settle down towards 2. Geometrically, the second point slides along the curve towards the
first, and the secant line swings round until it just touches the curve at $x = 1$. That limiting line
is the **tangent line**, and its slope, 2, is the rate of change of $x^2$ *at the single point*
$x = 1$.

Why 2 and not something else? A little algebra shows it. Expand $(1 + h)^2 = 1 + 2h + h^2$:

$$
\frac{(1 + h)^2 - 1}{h} = \frac{2h + h^2}{h} = 2 + h
$$

That matches the table exactly: $h = 0.1$ gives $2.1$, $h = 0.01$ gives $2.01$. As $h$ shrinks
towards 0, $2 + h$ gets as close to 2 as you like. This number, the slope you approach as the interval
shrinks to nothing, is the <Term id="derivative" />. The next lesson makes it precise.

:::note[Why not just set h = 0?]
With $h = 0$ the fraction becomes $\frac{0}{0}$, which means nothing: you cannot get a slope from
one point. The trick of calculus is to look at what happens *as* $h$ gets close to 0, without ever
reaching it.
:::

## Rates of change you will meet in ML

- **Loss versus a weight.** If increasing a weight $w$ makes the loss go up, the rate of change is
  positive, so you should decrease $w$. If the rate is negative, increase it. If it is 0, you may be
  at the bottom.
- **Loss versus training step.** A loss curve that flattens out (slope near 0) tells you training has
  stopped making progress.
- **Steepness matters.** A large rate means a small change to the input makes a big change to the
  output. That is useful to know, and sometimes dangerous, as you will see with learning rates in F6.

## Summary

- The slope of a line is $\frac{f(b) - f(a)}{b - a}$, the same for every pair of points.
- For a curve, the same fraction is the **average rate of change**: the slope of the secant line
  through two points.
- Shrinking the interval makes secant slopes approach the slope of the **tangent line**: the rate of
  change at a single point.
- For $x^2$ at $x = 1$, the secant slope is exactly $2 + h$, which approaches 2.
