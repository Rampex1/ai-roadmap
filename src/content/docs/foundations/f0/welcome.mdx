## What's in this module

This first module, F0, gets you set up and shows you how to learn effectively here. You don't need any programming
experience or any maths beyond high school; everything is introduced when it's needed.

1. **How to learn here**: why quizzes beat rereading, how spaced review and mastery checks work, and a study routine.
2. **Terminal basics**: typing commands to move around and manage files.
3. **Installing Python with uv**: a clean, reliable Python setup on your Mac.
4. **Notebooks**: JupyterLab on your Mac and Google Colab in the cloud, with a free GPU.
5. **Git and GitHub basics**: keeping a history of your work.

The module ends with a short setup homework and a mastery check. If you already know these tools, you can take the
mastery check first to test out.
