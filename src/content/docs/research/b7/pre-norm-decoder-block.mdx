A decoder layer has an attention sublayer followed by a position-wise feed-forward sublayer. In a <Term id="pre-norm-decoder-block" /> architecture, first normalize each token row, apply causal attention and add the result to the original row. Then normalize this updated residual stream, run the feed-forward network and add its output. Do not add the attention increment to the normalized input by mistake.

Layer normalization computes mean and variance over each token's features. Normalizing across token positions would allow a future token to affect an earlier normalized vector before the attention mask. The complete module may also contain learned per-feature scale and bias, which this centered-and-scaled fixture omits.

A position-wise feed-forward function mixes features but does not mix sequence positions. Position encodings or position-dependent attention biases distinguish order beyond content. In the notebook, use explicit tiny positional offsets to keep the end-to-end data path inspectable.

## Worked example

The two features are centered and scaled independently of all other tokens.

```python
def normalize_token(row,epsilon=1e-5):
    from math import sqrt
    if not row or epsilon<=0:
        raise ValueError("need a nonempty row and positive epsilon")
    mean = sum(row)/len(row)
    centered = [value-mean for value in row]
    variance = sum(value*value for value in centered)/len(row)
    return [value/sqrt(variance+epsilon) for value in centered]

print([round(x,3) for x in normalize_token([1,3])])
```

```text title="Output"
[-1.0, 1.0]
```

Keep the residual stream and the normalized sublayer input distinct.
