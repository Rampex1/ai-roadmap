For losses in [0,1] on n i.i.d. examples, Hoeffding gives a two-sided bound 2 exp(−2 n ε²) on the chance that one fixed hypothesis has absolute risk gap greater than ε. For a finite predetermined class with M candidates, the event that any candidate violates the gap has probability at most 2M exp(−2 n ε²). This union bound does not require candidate errors to be independent.

Requiring that bound to be at most δ gives n ≥ ln(2M/δ)/(2ε²). Round up to obtain an integer number of examples. <Term id="finite-class-generalization" cap /> lets us plug in a hypothesis chosen by ERM because the guarantee holds across the whole class on one event.

On that event, compare empirical risk of the ERM candidate with that of the population-best candidate. Each empirical-to-population replacement can add ε, so the excess risk inside the class is at most 2ε. These are sufficient worst-case bounds, and may substantially exceed practical sample requirements.

## Worked example

The raw bound is about 66.23 observations.

```python
def finite_sample_bound(size, epsilon, delta):
    from math import ceil, log
    if type(size) is not int or size < 1 or not 0 < epsilon < 1 or not 0 < delta < 1:
        raise ValueError("invalid finite-class bound inputs")
    return ceil((log(2) + log(size) - log(delta)) / (2 * epsilon**2))

print(finite_sample_bound(10,0.2,0.1))
```

```text title="Output"
67
```

Treat the bound as a guarantee under stated assumptions, rather than an estimate of the observed gap.
