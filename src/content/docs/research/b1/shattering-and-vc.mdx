A class shatters a set when every binary labelling of that set is realisable. <Term id="shattering-and-vc" cap /> is the largest shattered set size, or infinite if arbitrarily large finite sets can be shattered. To show dimension d, exhibit a shattered set of size d and explain why no set of size d+1 can be shattered.

Consider thresholds on the real line predicting one for inputs at or above the threshold. On n sorted distinct points, every labelling is a run of zeroes followed by ones. There are n+1 choices for how many zeroes appear first. A single point can receive either label, while the labelling (1,0) is impossible on two ordered points. The dimension is one even though the threshold parameter ranges continuously.

For an arbitrary class, the count for a particular set is not automatically the maximum over all sets of that size. This fixture is specific to one-direction thresholds, with distinct sorted points and both constant labelings allowed.

## Worked example

The labelling (1,0) does not appear.

```python
def threshold_labelings(n):
    if type(n) is not int or n < 0:
        raise ValueError("invalid number of points")
    return [(0,)*zeros + (1,)*(n-zeros) for zeros in range(n+1)]

print(threshold_labelings(2))
```

```text title="Output"
[(1, 1), (0, 1), (0, 0)]
```

To identify VC dimension, reason about realisable labelings rather than parameter count.
