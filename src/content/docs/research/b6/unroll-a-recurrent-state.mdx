A recurrent layer summarizes past inputs in a <Term id="unroll-a-recurrent-state" />. A scalar example computes $h_t = \tanh(w h_{t-1} + u x_t + b)$. The state changes with each token. The parameters w, u and b are reused across time. The output at one step can depend on earlier inputs even if only the current feature vector is supplied.

Unrolling rewrites this sequence as an ordinary graph with one copy of the operations per time step and shared parameter nodes. The state initialization is a separate choice. Reset it for independent sequences. Carrying it across unrelated documents can leak context and change results.

The fixture returns a sequence of hidden values without the initial state. Empty input produces the empty trace. Track the time axis separately from the batch and hidden-feature axes in a batched implementation.

## Worked example

Even the zero second input leaves a nonzero state.

```python
def unroll(inputs,w,u,b,initial):
    from math import tanh
    trace = []
    state = initial
    for value in inputs:
        state = tanh(w*state+u*value+b)
        trace.append(state)
    return trace

print([round(s,3) for s in unroll([1,0],0.5,1,0,0)])
```

```text title="Output"
[0.762, 0.363]
```
