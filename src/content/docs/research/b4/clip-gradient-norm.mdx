<Term id="clip-gradient-norm" cap /> can limit the impact of an unusually large gradient. Compute the Euclidean norm across the full gradient vector, including all chosen parameter groups. If it exceeds the cap, multiply all coordinates by cap divided by norm. This preserves direction. Clipping coordinates separately can change direction.

For a vector (3,4) the norm is 5. With cap 2.5 the scale is one half, giving (1.5,2). Do not normalize a smaller gradient up to the cap. Zero vectors need no division. With gradient accumulation, specify whether clipping happens before or after accumulation; those operations do not generally commute.

In mixed-precision training, inspect unscaled gradients before applying the intended cap. Record clipped fraction and norm summaries to distinguish occasional spikes from persistent instability. Clipping the gradient is distinct from directly bounding an adaptive optimizer's resulting parameter step.

## Worked example

Both coordinates are multiplied by the same factor.

```python
def clip_global(values,cap):
    from math import hypot
    if cap < 0:
        raise ValueError("negative cap")
    norm = hypot(*values)
    scale = cap/norm if norm > cap else 1
    return [value*scale for value in values]

print(clip_global([3,4],2.5))
```

```text title="Output"
[1.5, 2.0]
```

Log clipped fraction and define where clipping occurs relative to accumulation and scaling.
