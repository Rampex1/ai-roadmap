A <Term id="stacked-receptive-fields" /> grows as layers are stacked. Start with width r=1 and input jump j=1. A layer of kernel width k, dilation d and stride s changes the width to r+(k−1)d·j, using the old jump. Consecutive outputs then correspond to a new jump j·s in original input coordinates.

For two width-three layers with strides two and one, the first width is three and jump two. The second layer adds four original input positions of span, giving width seven. Padding can shift or crop the valid support near boundaries. It does not appear in this interior-span recurrence.

The structural field is a maximum span, not a guarantee all those pixels have equal influence. Dilation can produce holes. Pooling with known window and stride can use the same recurrence. Keep field width and jump separate when judging the spatial resolution of feature maps.

## Worked example

The second layer sees features spaced two original positions apart.

```python
def receptive_span(layers):
    width,jump = 1,1
    for kernel,stride,dilation in layers:
        if min(kernel,stride,dilation)<1:
            raise ValueError("invalid layer")
        width += (kernel-1)*dilation*jump
        jump *= stride
    return width,jump

print(receptive_span([(3,2,1),(3,1,1)]))
```

```text title="Output"
(7, 2)
```
